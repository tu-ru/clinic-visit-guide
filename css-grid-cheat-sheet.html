CSS Grid Cheat Sheet

Grid arranges items into rows and columns. First, make a parent element a grid container. Its direct children become grid items.

The dashed outline shows the grid container. Each shaded box is a grid item (a direct child of that container).

2. The three steps

  1. Select the parent that should control the layout.
  2. Set display: grid on that parent.
  3. Choose columns, spacing, and any special placement you need.
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}

In the clinic guide, .service-grid uses this pattern. The three service cards become three equal columns with 20px between them.

3. Column recipes

Three equal columns

1fr1fr1fr

repeat(3, 1fr) repeats three equally sized tracks.

Unequal columns

2fr1fr

2fr 1fr gives the first track twice the free space of the second.

fr means a share of available space. For example, 1fr 1fr splits the space evenly. minmax(0, 1fr) lets a track shrink when space is tight while sharing remaining space equally.

4. Grid lines and placement

Grid lines mark the edges of tracks. A three-column grid has four vertical lines. You can place an item between line numbers:

Column 1Column 2Column 3
.feature {
  grid-column: 1 / 3; /* starts at line 1, ends at line 3; spans two columns */
}

Remember: Grid lines are numbered from the start edge. The ending line is the edge where the item stops, so line 1 to line 3 covers two columns.

5. Responsive grids

Use a media query to change the number of columns on smaller screens. The clinic guide switches its service and contact grids from three columns to one.

.cards { grid-template-columns: repeat(3, minmax(0, 1fr)); }

@media (max-width: 760px) {
  .cards { grid-template-columns: 1fr; }
}

6. Grid or Flexbox?

  • Use Grid when you want to control rows and columns together, such as a card layout.
  • Use Flexbox when arranging items mainly in one direction, such as a row of navigation links.
