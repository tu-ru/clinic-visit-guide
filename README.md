# Clinic Visit Guide

A beginner-friendly static clinic information website built with HTML5 and CSS3. It uses a clean system-font stack, so no external font download is needed.

## Files
- `index.html` — page structure and content
- `styles.css` — colours, typography, layout, cards and responsive rules

## Concepts demonstrated
- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `footer`
- In-page links and navigation
- CSS variables, selectors, spacing and the box model
- Flexbox and CSS
- Hover and keyboard-focus styles
- Responsive design with a media query

## Important
This is an educational demonstration. CarePoint Clinic and all contact details are fictional. Do not add real patient information or present this as a real booking or medical advice system.
